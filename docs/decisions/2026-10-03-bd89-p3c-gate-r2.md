- AC8c: `"\ud800x second"` is replaced with `?` before the write, so `atomic_write`'s `write_text(..., encoding="utf-8")` (`io_utils.py:15`) cannot raise. W is not taken, C is reached, the file is valid UTF-8, and there is no skipped event. This is feasible: `str.encode("utf-8", "replace").decode("utf-8")` turns a lone surrogate into `?`. `surrogatepass` would produce invalid UTF-8, and the test's strict decode correctly rejects it. Event payloads do not carry the request. `EventLog` uses `json.dumps` with the default `ensure_ascii=True` (`event_log.py:149`), so a surrogate in an `error` string cannot break the log either.
