## Adversarial edges
1. Stale or mismatched snapshot: `pre_state["ok"] is True` but `pre_state["main_repo_root"]` != the detected main root. A wrong-repo snapshot with `dirty == {}` would allow reverts. The spec defines no comparison. It should fail closed.
2. Malformed ok snapshot: `{"ok": True}` with `dirty` missing or not a dict. The spec does not say whether that means "unavailable" or a crash, yet the wrapper must never raise.
3. Porcelain parse: renames (`R  old -> new`) and quoted paths (`"a b.py"`) give keys that match detection, since both use the same parse, so the membership check holds. But the batched `hash-object` fails on any such path, or on a deleted-file (` D`) path. One bad path then sets every blob to None and `changed_since_start` to None for all. Per-path hashing, or at least an AC, would help.
4. Race window: a path that was clean at snapshot time, then gets a user edit while the worker runs, and the worker also writes it. It is still reset and the user's edit is lost. This is residual and inherent, but the spec should state it.
5. Pre-call resolution: `_invoke_fix_llm` (and `_invoke_green_llm` on an in-run retry) now calls `_resolve_scratchpad`/`_resolve_worktree_root` before the LLM call. A ValueError that today only fires on the ok path would then crash the error path. The RED caller already guards this in `_pre_boundary_snapshot`; the spec should require the same guard (ValueError -> pre_state None -> fail closed).

## Findings
1. **MAJOR F1**: The spec omits collateral test-stub updates. The 4 `_maybe_emit_cross_tree_warning` lambda stubs in 3 test files (listed in Step 2) TypeError after GREEN. Fix: amend AC8 to list them as allowed edits (`lambda result, root, **_kw: result`) or state the alternative explicitly.
2. MINOR F2: Edges 1-2 (mismatched or malformed ok snapshot) need a one-line fail-closed rule in §2.
3. MINOR F3: Edge 5 needs a guarded pre-call resolution sentence in §2 Callers.
4. MINOR F4: AC7 static-check gaps (Step 3).
5. MINOR F5: Missing AC coverage for hash-object failure, changed_since_start False, and the metadata mirror. AC6 cannot discriminate.
6. MINOR F6: Spec should document the residual race window (edge 4) and the batched-hash degradation (edge 3).
