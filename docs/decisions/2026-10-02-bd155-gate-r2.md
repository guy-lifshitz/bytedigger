## Adversarial edges (not covered by §3)

1. **Heterogeneous mixed-shape log** (carried from r1, advisory). No AC puts a `type`-only violating event
   and an on-disk passing event in one list. Resolution is per event, so the risk is low.
2. **Whitespace-only `event_type`** (`" "`). §2.1 says "non-empty str", so `" "` wins over `type`. No writer
   emits it, and the spec is unambiguous. This is documentation of behaviour, not a defect.
3. **AC8 baseline permissiveness.** If a future stdlib version makes `json`/`re` transitively load `typing`,
   a `typing`-importing GREEN would pass AC8 vacuously. This cannot happen on the current interpreter. It is
   an advisory note on the guard's sensitivity.
