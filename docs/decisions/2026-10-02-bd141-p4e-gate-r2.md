## Adversarial edges (not covered by §3)
- **E-r2-a, in-session shadow.** On the sibling path, `_invoke_in_session` writes `observed_model` at :980 and *then* merges `extra_data` at :982-983. A caller's `extra_data["observed_model"]` therefore overrides the self-report there. It is the same defect class that AC8 exposes on the subprocess path. §6 excludes the in-session path. This lot does not introduce it.
- **E-r2-b, non-root init.** An init carrying `parent_tool_use_id="toolu_x"` with `model=haiku`, and no root model, should give None under "root only". No test pins this.
- **E-r2-c, first *valid* init.** With `[init("<synthetic>"), init("B")]`, the expected result is B. AC3b only pins A-then-B, so an implementation that takes the first init and then checks validity would wrongly return None and stay green.
- **E-r2-d, cross-backend semantics.** r1 E5 still stands. The agent-sdk accumulator applies no root filter and no `<`-skip.
