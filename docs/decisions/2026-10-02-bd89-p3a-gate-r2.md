## Ruling: AC16 "error" vs "degrade, not fail"

A recoverable `E_VALIDATION_RETRY` is **consistent** with §6 Q4 and with the §2 provider principle. It is not a hard failure: `engine.py:694-698` recurses on any `recoverable=True` result that carries `retry_from_step`. The retry re-runs `_build_spec_prompt` (the delta prompt) and then a fresh `invoke_spec_llm`. That call cannot replay, because the sentinel was unlinked by op2c and again by the engine's same-cycle `invalidate_cycle_sentinels` (`:752`). `_invoke_spec_llm` then unlinks the stale doc before the worker runs. The cost is one extra paid call, once per upgraded in-flight run. The asserted fields (`status`, `recoverable`, `error_code`, `retry_from_step == 0`, sentinel gone, no rewrite) are necessary.

They are **not sufficient** for the ruling's condition, which is a fresh re-invocation **at the same cycle with the same findings**. That also needs `cycle_count == cycle - 1` and the threaded keys (F2). The direction is approved. The payload must be pinned.

## Adversarial edges (not covered by any §3 AC)

1. **Replay at cycle 3 (gate-budget cycle).** A pre-upgrade surgical gate retry at cycle 3, replayed, goes to op2c. The default `cycle_count` sends the run back to cycle 2 and drops the gate findings and the gate spend. No AC covers cycle 3. This is the concrete instance of F2.
2. **False-positive op2c on a fresh post-GREEN call.** A worker writes the full body to disk but its chat reply is a fenced JSON array with `finding_id/old/new` keys, for example by echoing a finding table. A shape-only detector discards a valid rewrite and retries. A repeat hits `_MAX_SAME_CYCLE_RETRIES` and ends terminal, so the run fails instead of degrading. Whatever F1 resolution is chosen, it must state this trade-off and use a strict detector (all three keys on every element, top-level array only).
3. **Replay with `step_sentinel.disable` or a hashed ctx.** No edge: `invalidate_cycle_sentinels` removes both the legacy name and the hashed name and no-ops when sentinels are disabled. In that case nothing is replayed in the first place. No action.
