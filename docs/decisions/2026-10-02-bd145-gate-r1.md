## Deviation from the issue's fix shape (dispatcher strip instead of per-path helper)

The deviation is sound, and I prefer it to the issue's shape (Principle B, one chokepoint).
- `_BACKENDS[...]` is called from one place only, `llm_subprocess.py:1444` inside `_dispatch_backend`. Grep found no other prod caller of `_invoke_in_session`, `_invoke_subprocess`, `_BACKENDS[` / `_BACKENDS.get`, `_pin_mismatch_refusal` or `_capability_escape_refusal`. `conformance/` never passes `extra_data`.
- Both dispatches go through the strip: the main one (`:1755`) and the GH1169 fallback re-dispatch (`:1784`, which passes the caller's raw `extra_data` again).
- A per-path helper would need six sites (in-session, straggler, agent_sdk, pydantic_openai, pydantic_anthropic, anthropic_api) and would miss any third-party `register_backend` adapter. The strip covers all of them.
- On paths with no producer (straggler, echo backend) both designs give the same result: the name is absent, which is the existing first-class `not-checked` state.

## Adversarial edges (not covered by §3)

1. **Sibling warning-count collision.** A sibling test filters llm_subprocess WARNING records by the substring "mcp". The AC9 warning names `mcp_server_losses`, so it matches that filter (F1).
2. **Reserved key with a None value** (`{"observed_model": None}`). It must still be dropped and named in the warning. Untested (F5).
3. **`extra_data={}`.** Must stay a no-op with no warning. Untested, low risk (F5).
4. **Non-dict `extra_data`** (a Mapping proxy, or a list of pairs). Base `dict.update` accepts a list of pairs; a `.items()`-based strip raises AttributeError. The type hint is `dict | None` and no prod caller passes a non-dict, so this is advisory (F5).
5. **Fallback re-dispatch** logs the drop warning twice per call (F3).

## Findings

1. **MAJOR (F1): the change reddens an existing sibling test, and the spec forbids editing it.**
   - Test: `engine_py/tests/test_gh1194_mcp_server_losses.py::test_ac17_data_key_is_full_list_and_cannot_be_shadowed`, assertion at `:938`.
   - Run 2 calls `invoke_llm_subprocess(..., extra_data={"mcp_server_losses": "SENTINEL_MUST_NOT_SURVIVE"})` (`:935`) under `_capture_module_warnings()`, then asserts `second.mcp_messages == []`.
   - `mcp_messages` keeps every WARNING on `llm_subprocess.logger` whose text contains "mcp" (case-insensitive, `:205-207`). The handler is on the module logger, so a record from a child logger would also be caught.
   - The AC9 warning must name the dropped field, so its text contains "mcp", and GREEN will turn this test red.
   - Spec §1 item 6 says the sibling tests are kept, and §4 puts existing tests out of scope. Both are wrong, and GREEN cannot pass without breaking §1s.
   - Fix (pick one and freeze it in the spec): (a) add test_gh1194 to §4 with a named, minimal edit. For example, give the drop warning a fixed prefix such as `reserved observation field(s) dropped:` and have `mcp_messages` exclude records with that prefix. (b) Drop the `extra_data` sentinel from that test's run 2, since AC10 and bd145 now pin the no-shadow property. Option (a) keeps more coverage.
   - Then add test_gh1194 (and test_bd141_p4e) to the §1a sibling list as "touched / verified".
2. **MINOR (F2): unverified citation.** `reference_backends/anthropic_api.py:278` is cited as a shadowing merge but I did not confirm it (the grep shows only `manifest_source=` registration at `:301`). Re-verify, or remove it from §1 item 4. Advisory only, since that file is out of scope.
3. **MINOR (F3): "logged once" is ambiguous.** On the GH1169 fallback (`:1784`) the strip runs twice for one call and logs twice. Say "once per dispatch", or move the strip and log to `invoke_llm_subprocess` before `:1755` and pass the stripped dict to both dispatches. The latter is still a single chokepoint, because `invoke_llm_subprocess` is the only entry to `_dispatch_backend`.
4. **MINOR (F4): no reddening change named for AC10.** In "which change reddens each negative", add "AC10: moving the producer lines `:2416-2434` before the `extra_data` merge".
5. **MINOR (F5): untested edges.** `{"observed_model": None}` (dropped and named), `{}` (no warning), and `None` (backend receives `None`; AC7 checks `seen[0] is not None` only on the non-None case). Add one parametrised case. State in §2 that a non-dict `extra_data` is out of contract.
6. **MINOR (F6): full-suite delta required.** §1r: GREEN must run the full engine_py suite plus the delta, not only the bd145 file. F1 shows a scoped pass will not catch the sibling regression.
