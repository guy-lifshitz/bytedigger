## Adversarial edges (not covered by §3)

1. **Non-dict Mapping, or a list of pairs, gets through the strip.** §2 filters only `dict`, but the in-session path (`:982-983`) and the straggler path (`:2046-2047`) still call `data.update(extra_data)`. That accepts any Mapping (e.g. a `collections.UserDict` or `MappingProxyType`) and any iterable of pairs.
   - So `extra_data=[("observed_model", "claude-opus-5-5")]` would shadow the producer on both paths and skip the dispatcher.
   - It is outside the `dict | None` type contract, mypy-checked, and no prod caller does it, so this is not blocking. But it is the one input that defeats the "closes the whole class" claim (F-r2-2).
2. **Prefix text containing "mcp".** If a future prefix edit added "mcp", gh1194's exclusion would still work, because it excludes by prefix rather than by substring. No issue.
