## Adversarial edges (not covered by any §4 AC)

1. **In-process cache staleness (MAJOR-4).**
   - HAL `_TEXT_CACHE` (lib:151, 184-194) is a module-global, process-lifetime cache of every scope, corpus and **spec** file read. In HAL the lib is a fresh process per call. In the port, `audit()` runs inside the long-lived engine process.
   - A validation cycle that loops back to phase 5 after GREEN edited the scope files, or after the spec was amended to cite a sibling, re-audits against the cached old text. The result is phantom or missed MISSING rows, and the cache grows without bound in MCP/long-lived hosts.
   - B5 uses a fresh tmp path per case, so nothing catches it.
2. **Graph JSON that parses but is not an object** (`[]`, `{"nodes":"x"}`). A verbatim `_graph_callers` raises AttributeError. In the CLI that is a traceback with exit 1, read as "MISSING present" (MAJOR-2). In phase 5 it is `detector_error` on every run of any repo with such a `graphify-out/graph.json`.
3. **Graph with real caller edges.** The graph half's path resolution and its rows (key = bare symbol, not `symbol(`) are never exercised. This is the same gap as HAL.
4. **Realpath mismatch in phase 5.**
   - `resolved_paths` are `Path.resolve()`d (phase_5:4121), while `git_cwd` is not (4117). `audit(corpus_root=git_cwd, exclude=resolved_paths)` with HAL's `abspath` exclusion silently fails under a symlinked cwd (macOS `/var`, symlinked worktrees).
   - `scope_files_from_spec`'s "inside root" check can drop every entry if only one side is realpath'd, which yields `no_scope_files` forever.
   - B5 realpaths its root, which hides both (MINOR-2).
5. **Default walk outside git.** `git rev-parse` exits 128 there, not OSError. HAL emits no warning on rc≠0 (lib:597-604). The spec says "after W_GIT_ROOT_UNRESOLVED" without saying whether a nonzero rc also warns. Untested (MINOR-4).
6. **Corpus name pattern on non-HAL consumers.** `test_*.py|*.test.ts|*.test.sh` misses `*_test.py`, `.test.js` and `.spec.ts`. A bd consumer project gets `E_NO_TEST_CORPUS` skipped, or a visible but meaningless `clean`. This is a fidelity choice; document it as a known limitation (MINOR-6).
7. **Scope files not excluded from the corpus.** HAL `main` always passes `exclude=scope_files` (lib:973). §2.2 describes `exclude` only as a caller parameter, and the phase-5 call replaces it with `resolved_paths`. A `--scope-file tests/test_x.py`, or a `conftest.py` scope entry, self-matches (MINOR-1).
8. **Row tie order.** HAL `sort -k1,1 -k2,2n -k6,6n` has a constant key 6 (`"0"`), so same-(file,line) rows fall back to whole-line bytewise order (func, token, channel). §2.2 omits this last-resort key, so a stable-sort GREEN diverges from HAL. B2 compares port to port only (MINOR-5).
9. **Unbounded in-process scan.** The old helper had `timeout=30`. The port has no bound, and a naive O(lines x keys) scan over a 5000-file default walk sits inside phase 5. Recommend a prefilter (one compiled alternation of escaped keys per channel) and/or a documented cap (MINOR-7).
10. **`--json` with exit 2** (SiblingAuditError, argparse usage). Whether stdout carries the JSON doc is unspecified (MINOR-4).
11. **Duplicate channels.** `--channels import,import,...` x7 counts as the full set in HAL (shell :204-213). "partial_channels" is not defined in §2.2 (MINOR-4).
12. **py3.9.** `clean-room.yml:78` runs 3.9 as expected-fail, so the 3.9 constraint and B6b's `_STDLIB_FALLBACK` branch are never executed in CI. The fallback set also lacks legitimate stdlib modules such as `errno`, `stat`, `codecs`, `locale` and `tempfile` (MINOR-10).

## Findings

1. **BLOCKER-1: the spec keeps a `claude` token that the RED forbids.**

   - Fix (spec): drop both subpath prunes from the module (or make `prune_subpaths` an `audit()` parameter defaulting to `()`), and state the deviation from verbatim in §2.1. Keep `_PRUNE_DIRNAMES`, minus `memory-backups` if you want it fully HAL-neutral.
   - Fix (RED): optionally add a P31 leg asserting a `.claude/worktrees/test_x.py` is **not** pruned, to pin the chosen behaviour.
2. **BLOCKER-2: §3 misses the error-code registry siblings.**

### MAJOR

3. **MAJOR-1: the no-spec verdict contradicts HAL** (spec:85-86).
   - HAL emits `MISSING` (lib:1216; HAL spec §1.1 lines 73-77). With the spec's `-`, `--require-clean` without `--spec` exits 0 over coupled rows, where HAL exits 1.
   - Fix (spec): "no spec ⇒ every row `MISSING`", as HAL.
   - Fix (RED): `--scope-file value_const.py --channels`-default `--require-clean` with no spec and no caps gives exit 1, and every row's verdict is `MISSING`. Use a scope/corpus that binds no cap; P02's argv qualifies.
4. **MAJOR-2: no exit code for an internal crash** (spec:124-128).
   - HAL maps any lib failure to `E_COUPLING_LIB_FAILED`, exit 2 always (shell:761-763; HAL §1.7 row 5). In the port, an uncaught exception exits 1, which is indistinguishable from "MISSING present". Edge 2 makes this reachable from a malformed `graph.json`.
   - Fix (spec): `main()` catches `Exception`, prints `E_SIBLING_AUDIT_INTERNAL <ExcName>` (register it, per BLOCKER-2) and returns 2. `_graph_callers` treats a non-dict JSON / non-list nodes/links as `graph_unreadable`.
   - Fix (RED): (a) `--graph <tmp file containing "[]">` gives exit 0, `reason=graph_unreadable`, `W_GRAPH_UNREADABLE`. (b) An in-process `main([...])` with `audit` monkeypatched to raise gives return 2 and the code on stderr.
5. **MAJOR-3: the phase-5 wiring is stub-passable** (test:714-718; spec:150).
   - `spec_path=None` at both call sites passes every test, and AC2 is dead in production.
   - Fix (RED): for each call, assert `ast.unparse(kw.value) == "prev.data.get('spec_path')"` (`ast.unparse` exists on 3.9+). Better, add one host-level test that drives `_verify_red_lint_rules` far enough to observe a `red_sibling_audit_*` event carrying a non-`no_spec` reason.
6. **MAJOR-4: the process-global `_TEXT_CACHE` is ported into an in-process library** (spec:58-63 "verbatim"; HAL lib:151, 184-194).
   - Stale spec/scope/corpus text is reused across `audit()` calls in the long-lived engine (validation-cycle loop-back to phase 5, MCP host).
   - Fix (spec): the read cache is scoped to one `audit()` call (created and discarded per call, threaded or reset at entry).
