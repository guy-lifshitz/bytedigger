## Adversarial edges (not covered by any AC)

1. Non-adjacent duplicates in a larger list, for example jobs `[A, B, A']`. Every RED identical-case uses all-identical or exactly two jobs, so an adjacent-pair-only comparison passes the whole RED and still lets an identical pair through. (MINOR: add a 3-job `[A, B, A']` case.)
2. Error precedence: a list with a blank-role job AND an identical pair. `IdenticalFanoutError` subclasses `ValueError`, so either branch satisfies a bare `pytest.raises(ValueError)`. Precedence is unspecified, but the safe outcome (zero calls) holds either way.
3. A dispatcher nested inside a dispatcher's arguments, for example `Thread(target=lambda: executor.submit(invoke_llm_subprocess, ...))`. Per spec the subtree rule gives two findings. This is unpinned, and the over-count is harmless for the insurance layer.
4. `prompt=""` with a non-empty `input_text` (see Step 1 drift). The composed prompt is not whitespace-only, so it is allowed.
5. Unicode canonical-equivalence (NFC/NFD) or compatibility variants are not collapsed. Only whitespace and casefold are normalized. Accepted by spec design, not a defect.
6. `main()` against the real tree before #317 returns 1, because the real site is a finding. Only AC10 reasons about the real tree, and no root driver is wired here. This is acceptable because spec scope excludes the driver and #317 removes the site.
