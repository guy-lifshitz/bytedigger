## Adversarial edges (not covered by the §4 AC table)

1. **Date-dependent suite outside this file (regression shield / time bomb).** The autouse `_utc_today` pin exists only in the M10 test file. The §5 tests (`bd89_p3b1` ac9b, F7830037, GH1399 x4 incl. ac9, bd92, `bd89_p3b1b_ii::test_ac5`, CF838E6F ac6/ac9) feed findingless input and expect `ok`. Under the r4 default (shadow) they **pass unchanged** until real UTC date 2026-10-18. Then, with no code change, they all turn red at once because expiry flips them to enforce. Conversely, §5's option "expect the new error" fails **now** unless the rewritten test sets the flag. §5 was written for the r3 always-enforce design and does not say which (MINOR-2).
2. **Shadow-then-enforce same-run restart.** A shadow run persists the normalised doc and writes `.rejected.md`. The flag is then flipped (or the date crosses expiry) and the run is restarted. Under enforce, `doc_path` exists (normalised text) **and** `.rejected.md` exists. §1 L31 says `os.replace` doc_path (which overwrites `.rejected.md`), while L32 says keep an existing `.rejected.md`. If GREEN honours keep-first by skipping the move and does not `unlink` doc_path, phase 7 sees PRESENT on a terminal failure (MINOR-3).
3. **Multi-cycle stale evidence.** Keep-first means a cycle-2 findingless review leaves cycle-1's `.rejected.md` in place. In enforce the error message then points the operator at stale bytes, and in shadow the event `bytes` no longer matches the file. Nothing clears `.rejected.md` when a later cycle succeeds (MINOR-4).
4. **Mixed object / non-object list** (`["x", {"severity": "INFO"}]`). One object entry with no recognised severity gives `unrecognised_severity` by the precondition, while the string entry is silently dropped. This is defensible but unpinned. Same for `["CRITICAL: x"]` + `VERDICT: FAIL`: §2 implies the marker wins (FAIL, ok), but there is no cell (MINOR-5).
5. **Alias env leak.** The autouse fixture deletes only `HAL_REVIEW_EMPTY_FALLBACK_ENFORCE`. `_aliased_env_get` also honours `BD_REVIEW_EMPTY_FALLBACK_ENFORCE` / `BYTEDIGGER_REVIEW_EMPTY_FALLBACK_ENFORCE`, so a developer shell with an alias set flips every shadow cell to enforce (MINOR-9).
