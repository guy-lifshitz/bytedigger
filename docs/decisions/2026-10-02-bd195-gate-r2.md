## Step 3. RED adequacy
- **Failure mode.** Failures happen at assert time inside the test bodies. The orchestrator reports 36 failures, which matches 28 plus AC4b ×4, the per-shape AC8 ×2, the str-identity CLI case and the override test. All imports are deferred.
- **No stub-passability.** The UUT is never mocked. The stubs are inputs.
- **Timing and flakiness.**
  - Expected wall time for each sleep kind is about 0.4s (2 adversaries × 0.2s), against a 2.5s bound. That is a wide margin.
  - Abandoned 5s daemon workers outlive their test. They are daemon threads, so bd27's non-daemon predicate and interpreter shutdown are unaffected.
  - A woken `SleepingFreeze` calls `compute_digest` on a deleted temporary directory. A correct guard boxes that error. A guard that doesn't would raise only a warning, since there is no `filterwarnings=error`.
- **The daemon predicate and pytest-timeout.** With `--timeout` (CI) and the default method on Linux (`signal`), pytest-timeout starts no thread. Under `timeout_method=thread`, its `threading.Timer` (non-daemon) would false-fail the check. bd27's AC-E10 predicate has the same exposure, and CI is ubuntu-only. Advisory A2.
- **AC7 literal.** Still correct by my r1 hand check. It is still not reached on the pre-GREEN tree, because `run_adversaries(adapter=None)` raises `TypeError` before it (r1 finding 3, MINOR, unchanged).

## Adversarial edges (not covered by any spec AC)
1. **Interrupt racing a timeout.** A `KeyboardInterrupt` raised by `freeze` after its timeout has expired is lost with the abandoned worker. That is acceptable, and it is the same behaviour as `evaluate_guarded`. No AC is needed. Informational.
2. **An `identity` property that raises.** For example, a lazy backend probe inside the identity getter. Change 5 implies `ValueError` ("missing or malformed"). The RED's `Missing` case covers only `AttributeError`. A GREEN using `getattr(adapter, "identity", None)` turns `AttributeError` into the `None` branch, but lets any other exception from the property escape. In the CLI that is an uncaught traceback with exit 1. MINOR.
3. **A non-str `level_claimed` or a bad `--timestamp`.** Neither is validated. That is out of scope for this seam, and `validate_attestation` already ignores an unknown level when comparing. Informational.
