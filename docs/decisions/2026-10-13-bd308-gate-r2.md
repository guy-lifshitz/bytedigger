## New blocking findings
1. AC11 (`test_ac11_nested_path_is_reported_in_full`) cannot pass with a correct GREEN and pollutes the real tree.
   The default clone makes `repo/engine_py` a SYMLINK to the real engine root (`_installed_clone`, symlink branch).
   `rel = "engine_py/tests/sub/test_x.py"` is written THROUGH the symlink (`_stage` -> `write_text`), and
   `git add` of a path beyond a symbolic link fails ("beyond a symbolic link"), so `_stage` asserts at setup.
   Evidence: the untracked stray file `/Users/guy/.hal-worktrees/wt-n308/engine_py/tests/sub/test_x.py` already
   exists in the real worktree. It is also a collectable failing test (NameError run_scan) and a one-finding
   file that a GREEN `git add -A` would commit. Fix: use a nested path outside the symlink (e.g.
   `tests/sub/test_x.py`; spec AC11 and the `file=` string follow), and delete the stray `engine_py/tests/sub/`
   directory (orchestrator, not the gate).
2. AC2 pins the wrong denominator. `precommit_enforce.registry_names()` sweeps every `*_LINTS` list including
   TEXT_LINTS: today SPEC 9 + TEST 2 + TS 1 + TEXT 1 = 13 names; appending to TEST_LINTS gives 14.
   `test_ac2_registry_lists_the_driver_and_the_denominator_is_13` asserts `len(names) == 13` and
   `len(set(names)) == 13`: a correct GREEN yields 14, so the RED cannot go green. The "12 -> 13" of the older
   pins is the SPEC+TEST+TS formula (bd66 ALL_REGISTRY_NAMES, bd302/bd304 `denominator`), which excludes TEXT
   and is correct there. Fix: assert 14 in AC2 (and say in spec 2.2/AC2 that registry_names() goes 13 -> 14 while
   the older SPEC+TEST+TS pins go 12 -> 13). The `_OTHER_DRIVERS` list (11) is correct; 14 names - 2 absent = 12
   drivers incl. this one.
3. Spec contradiction: 2.2 names the table `RATCHETED_NAMES`, but 2.3 still says "only for names in
   `RATCHETED_LINTS`". The RED asserts `not hasattr(precommit_lints, "RATCHETED_LINTS")`; a GREEN following 2.3
   literally defines the forbidden name and also breaks the three `_LINTS` fence pins. Fix: 2.3 -> `RATCHETED_NAMES`.
