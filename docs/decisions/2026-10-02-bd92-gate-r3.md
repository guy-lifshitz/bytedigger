## Adversarial edges (not covered by §6 ACs)

1. **Unanchored `str.replace` in the glob builder.** A non-hashed name whose run_id ends in `_hhhhhhhhhhhh` would have its tail rewritten to `_h*.json`. The same applies to a step or workflow name containing `_c-1_r`. The spec declares both out of contract (:117-118), and production run_ids are uuid hex. Advisory: anchor the hash replacement with `endswith`, and do the cycle replacement once, from the right.
2. **`_write_ship_sidecar` fails after the pre-SHIP unlink.** A finalized SHIP then leaves no sidecar, so the next run has no prior base. This is fail-safe (it degrades to a full write) and is not a regression.
3. **The AC15c run-ctx cycle (2) disagrees with the prev cycle (1).** GREEN must take `cycle` from `_prev_fields` (spec :77, "`_build_spec_prompt` at `cycle == 1`"). If GREEN keys off the telemetry cycle, it still passes AC15c vacuously, but AC15a and gh636 `test_ac8` pin the prev-cycle reading. No finding.
