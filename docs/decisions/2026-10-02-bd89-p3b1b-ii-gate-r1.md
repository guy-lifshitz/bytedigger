## Adversarial edges (not covered by §3)

1. **Non-regular composite path.** If `role-composite.md` is a directory, the result depends on how GREEN tests for "missing". With `is_file()` it becomes `role_report_missing` and the stdout fallback. With `exists()` it becomes the unreadable branch and SUSPECT. Op1 does not specify which predicate to use (A2).
2. **Absent `reviews/` dir.** AC5 has the dir with a leftover file, and AC6 has an empty dir. No AC pins that `role_report_missing` also fires when `reviews/` does not exist. The old code short-circuited on `is_dir()`, so GREEN could carry that guard over and skip the event (A2).
3. **Retry duplication beyond the audit event.** On a writer retry, the second aggregation also re-emits `composite_finding_quote_verified` (once per finding), `reviewer_suspect_rate`, `reviewer_grep_accuracy_warning`, `role_report_malformed`, `review_zero_findings_suspect`, `role_report_missing` and `review_aggregation_error`. §6 names only `review_findings_audit`. No prod consumer counts these events today (grep), so the impact is nil, but the decision record is incomplete (A1).
4. **Decoy fence for the stale guard.** Nothing pins that the narrowed guard leaves legacy `role-<slug>.md` untouched, or that it does not grow back into a broader `glob("role-*")` / `iterdir`. AC10's regex catches only the exact `glob("role-*.md")` literal. The impact is harmless because leftovers are ignored (AC4), so no fix is required.
