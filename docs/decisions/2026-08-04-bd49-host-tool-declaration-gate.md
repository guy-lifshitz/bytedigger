# bd#49 — производный гейт объявления на хост-инструмент

**Class:** перечислительный allowlist, выдающий себя за политику.
**Chokepoint:** `engine_py/tests/helpers/host_tools.py` (`HOST_TOOLS`, `skip_without`,
`pytest_runtest_makereport`) + новый производный гейт
`engine_py/tests/test_bd49_host_tool_declaration_gate.py`.
Вытесняемый перечислительный слой: `_C4_BUN_CALL_SITES` / `_C5_SEMGREP_CALL_SITES` /
`_C6_DOCTOR_GIT_CALL_SITES` в `test_bd102_host_tool_contract.py`.

---

## §0. Замер, который переписал задание issue

Issue bd#49 предлагает слой принуждения дословно так: «сканировать тела тестов на
`shutil.which("<tool>")` для `tool ∈ HOST_TOOLS` и требовать от каждого такого тела
ЛИБО `skip_without`, ЛИБО объявленный маркер отказа».

**Живой замер (AST, транзитивное замыкание вызовов внутри файла, корпус на `b95e48a`):**

| множество | число тел `test_*` |
|---|---|
| достигают `which(<host tool>)` — домен предложенного гейта | **37** |
| достигают хост-инструмент литералом argv (`subprocess.run(["git", …])`) **без единого** `which` | **610** (79 файлов) |
| оба признака | 28 (входят в 37) |
| только `which` | 9 |

**Гейт, ключующийся на `which`, видит 37 из 647 достижимых тел — 5.7%.** Если считать
его слоем принуждения политики «нет инструмента ⇒ объявись», он ровно тот же класс,
который issue обвиняет: множество обязанных задано признаком, который большинство
вызывающих сайтов просто не содержит. Освобождение снова молчаливое.

**Но 610 — не дыра, и вот почему.** `host_tools.py::pytest_runtest_makereport` уже
**тотален** по этому множеству: любой тест, упавший `FileNotFoundError` с
`basename(filename) ∈ HOST_TOOLS` при замороженной недоступности, конвертируется в
`skipped` независимо от того, как он звал инструмент. `docs/host-requirements.md`
фиксирует это же числом: «без git ~500 тестов поднимают `FileNotFoundError('git')`»
и они становятся пропусками автоматически, ни одной строки объявления не требуя.

⇒ **Домен гейта — не «все, кто трогает инструмент», а «все, кто ПЕРЕХВАТЫВАЕТ
автоматическую конверсию, опрашивая доступность сам».** Пре-эмптивный опрос — это
единственный способ уйти из-под тотального механизма: тело, вызвавшее `which` и
принявшее решение до того, как полетит `FileNotFoundError`, механизму невидимо.
Тех тел ровно **37**, и это **полное** множество побегов, а не выборка.

Формулировка политики, которую гейт принуждает, поэтому такая:

> Тело теста, которое **само опрашивает** доступность хост-инструмента, обязано
> объявить, что оно делает с ответом: либо санкционированный `skip_without(tool)`,
> либо явный маркер отказа с доводом. Молчаливого третьего пути нет.

## §1. Что замер нашёл сверх issue: порядков не два, а пять

Issue называет два порядка. В корпусе их **пять**, и три из них issue не видит:

| # | форма | где | замороженная карта? |
|---|---|---|---|
| 1 | `skip_without(tool)` | 9 сайтов, `host_tools.py` | **да** |
| 2 | жёсткий `assert which(...) is not None` с доводом | `test_gh1338_corpus_parity_gate.py::_build_parity_fixture` L107 | нет (сознательно) |
| 3 | инлайновый `if which("git") is None: pytest.skip(...)` | `test_GH294_constitution_worktree_telemetry.py` L91 | **нет — живой `which`** |
| 4 | локальный хелпер `_skip_if_no_git()` | `test_BF7890C8_collect_probe_parent_venv.py` L61 | **нет — живой `which`** |
| 5 | `@pytest.mark.skipif(not _has_git(), …)` | `test_phase_45_spec_D02C615D.py` (12), `test_phase_45_spec_DA5330E9_suffix_map.py` (12) | **нет — живой `which`, на импорте** |

Формы 3/4/5 — **не стилистический разнобой, а нарушение задокументированного
инварианта**. `host_tools.py` в собственной докстроке пишет: «Neither this hook nor
`skip_without` may call `shutil.which` live afterward: two tests monkeypatch
`shutil.which` process-wide, which would otherwise make a live lookup report a tool
absent on a machine that has it». Формы 3/4/5 делают именно живой `which` — то есть
**подделываемы тем самым monkeypatch'ем**, ради которого заморозка и вводилась.
Форма 5 хуже прочих: `skipif` вычисляется на импорте модуля, то есть до
`pytest_configure`, и поэтому не может консультироваться с замороженной картой в
принципе.

Это самостоятельный дефект, а не косметика, и он чинится этим же PR (M2).

## §6. Acceptance criteria

Гейт живёт в `test_bd49_host_tool_declaration_gate.py`. Сканер вынесен именованной
функцией (§1aa) `undeclared_host_tool_probes(source: str) -> list[tuple[str, str]]`,
принимающей **исходный текст**, а не путь — иначе отрицательную ногу нечем кормить.

- **AC1 (§1l, якорь на реальный побочный эффект).** Прогнанный по реальному каталогу
  `engine_py/tests/**/test_*.py` гейт возвращает **пустой** список необъявленных
  проб. Это утверждение о живом корпусе, не о фикстуре.
- **AC2 (положительная нога, форма `skip_without`).** Исходник с телом, зовущим
  `which("bun")` и `skip_without("bun")`, даёт пустой список.
- **AC3 (положительная нога, маркер отказа).** Исходник с телом, зовущим
  `which("bun")` и несущим комментарий `# host-tool-hard-fail: <довод>`, даёт пустой
  список.
- **AC4 (ОТРИЦАТЕЛЬНАЯ НОГА — гейт, не падающий на новом сайте, инертен).**
  Исходник с телом, зовущим `which("bun")` и **не** несущим ни одной из двух форм,
  возвращается сканером ровно одной записью `(func, "bun")`. Без этого AC гейт —
  декорация.
- **AC5 (отрицательная нога, транзитивная).** То же, но `which("bun")` спрятан в
  хелпере `_fixture()`, который зовёт тело теста: запись всё равно возвращается.
  Прямой-только сканер сегодня пропустил бы **8 ACs `gh1338`** — именно те, что
  issue называет предметом.
- **AC6 (маркер обязан нести довод).** `# host-tool-hard-fail:` с пустым хвостом
  объявлением **не считается** — запись возвращается. Пустой маркер = молчаливое
  освобождение под видом объявления, то есть исходный класс.
- **AC7 (объявление не течёт между телами).** Два тела в одном файле: первое
  объявлено, второе нет ⇒ ровно одна запись, и это второе. Ловит сканер, ищущий
  маркер по файлу целиком вместо тела.
- **AC8 (объявление привязано к инструменту).** Тело зовёт `which("bun")`, но несёт
  `skip_without("git")` ⇒ запись возвращается. Ловит сканер, сверяющий факт вызова
  вместо аргумента.
- **AC9 (§1a, sibling).** `test_bd102_host_tool_contract.py::test_ac5b_…` проходит на
  голове ветки без правок — M2 не задел ни один из 8 перечисленных сайтов.
- **AC10 (алиасы).** `import shutil as _sh; _sh.which("bun")` и
  `from shutil import which; which("bun")` оба распознаются. В корпусе живут три
  алиаса (`_shutil`, `_sh`, `_shutil_real`) — сканер обязан ключевать на имя
  атрибута/имени, а не на модуль.
- **AC11 (граница честности гейта).** Сканер **не** обязан ловить пре-эмпцию, сделанную
  не через `which` (например `os.path.exists("/usr/bin/git")` или собственный
  `except FileNotFoundError: pytest.skip(...)`). Замерено: в корпусе таких **ноль**
  (`except FileNotFoundError` рядом со `skip` — 0 попаданий; `exists()` по путям
  бинарей — 0). Гейт обязан **назвать** эту границу в докстроке, а не умалчивать её.

## §7. Что PR НЕ утверждает

- Не утверждает, что корпус целиком инертен-безопасен при отсутствии инструмента:
  тотальность даёт хукврапер, гейт закрывает только побеги из-под него.
- Не утверждает, что `_C4/_C5/_C6` больше не нужны — см. §1v.
- Не утверждает, что форма 2 (жёсткое падение) неверна. Она остаётся законной,
  но становится объявленной.

- **Прибор** (`test_bd49_host_tool_declaration_gate.py`, ACs 2-10): **9/9 зелёных**.

  отрицательных пропустили бы** — обе стороны нужны.

сканера. Затем полный прогон и дельта против базы выше.
