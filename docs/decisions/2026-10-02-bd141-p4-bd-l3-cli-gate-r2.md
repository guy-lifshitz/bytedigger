## Adversarial edges (not covered by the §3 AC table)

1. **Both keys present and disagreeing**, e.g. `{"type": ET, "event_type": "x"}`. This was r1 edge 1 and is still untested. Under §2.1's OR rule it must be read. A GREEN of the form `event.get("event_type") or event.get("type")` would skip it. No production writer emits both keys, so the impact is low.
2. **Line numbering with blank lines.** A blank line before a malformed one, e.g. `{"a":1}\n\n{bad\n`, must report `line 3`. A GREEN that counts only non-blank lines would report `line 2`. AC8's fixture has no blank line, so it cannot tell these GREENs apart.
3. **Whitespace-only line in the middle of a valid log** (`"  \n"`). §2.2 says skip it. A GREEN that calls `json.loads` on it would exit rc 2. Not tested.
4. **Inherited `HAL_LLM_PROVIDER` in the subprocess environment.** `_family` → `get_provider()` reads the environment (`llm_provider.py:144`). If the variable is set to a provider that is registered only in-process, the child process raises KeyError and the CLI fails with a traceback. This is a property of the environment, not of the CLI contract. Advisory: GREEN may let it propagate.
5. **Run-id type mismatch** (a non-string `run_id` in the log versus the string from argv). Strict `==` never matches. This was r1 edge 6 and remains unspecified. Advisory.
