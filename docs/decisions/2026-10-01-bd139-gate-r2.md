## Adversarial edges (not covered by §4)

1. **Shared anti-fab fragment in the single prompt.** `_get_anti_fab_prompt()` is appended
   unconditionally (`phase_6_review.py:921`) and contains "sub-agent" (BLOCKER 1).
2. **Parallel→single mode switch on resume.** The six `role-<parallel-slug>.md` files survive
   because only `role-composite.md` is unlinked. They satisfy floor 1, and their findings
   aggregate as current (NOTE 1).
3. **Single reviewer writes nothing in cycle N ≥ 2.** `E_NO_ROLE_FILES` is skip-on-error
   (`:1488-1492`). `_write_review_artifact` then adopts the on-disk `build-review.md` from cycle N-1
   through the disk-first `_resolve_review_content` (`:2006-2012`). AC6b asserts only the
   aggregator step (NOTE 1).
4. **Gate step re-entry on resume.** A second row is written for the same `detail.cycle`. The
   invocation run_id is freshly minted, so `build_id` differs across a resume. The §5 per-round
   classifier double-counts one round and splits one build (NOTE 2).
5. **Structured `approve=False` with markdown `PASS`.** The row carries `detail.verdict == "PASS"`
   for a rejected round, and the `reason_code` mapping is unstated (NOTE 3).
6. **Injection-block exit.** It is non-PASS and not logged, which contradicts the "every non-PASS
   outcome" wording (NOTE 4).
7. **Budget-exhausted `E_SPEC_DEFECT_BUDGET` site** (`:6904`): no test (NOTE 5).
8. **In-session `E_LLM_NO_RESULT_EVENT` retry.** A late write from the first nonce's servicer can
   land after the second call's unlink and be read as fresh. This class existed before the change;
   listing it is enough.
