## Step 3: RED adequacy

- MAJOR F2: no test asserts the manifest leg of the union at all. ## Adversarial edges (not covered by §3)
1. Manifest test file plus RED: both present and on disk, expect both in argv, and a path that is in both appears once (dedupe, n_total). (Covers F2.)
2. Path-spelling dedupe: persisted file lists `./tests/test_x.py` or an absolute path, manifest lists `tests/test_x.py`; should de-dupe to one. `_read_red_test_paths` returns lines UNSTRIPPED, so whitespace-padded lines must be stripped before the existence check.
3. Path escape: RED line `../outside/test_x.py` or an absolute path outside git cwd that exists on disk; "exist under the git cwd" must reject it.
4. `prev.data["red_test_paths"] == []` (list, empty) alongside a non-empty persisted file: does the file apply or not? Spec says "when it is a list", so it would be ignored; pin one behaviour.
5. Root-level source file (`mod.py` in repo root): "same directory" pulls in every root `test_*.py`; and a short or generic stem (`__init__`, `a`) matches by substring and floods the 50 cap. Decide: non-recursive same dir, and whether `__init__` is excluded.
6. Cap interplay: >50 siblings where some are already RED/manifest: is the cap applied before or after removing those, and is RED/manifest ever truncated? RED must never be dropped by the cap.
7. Source file deleted by the fix (in manifest, gone on disk), and manifest test file deleted: `git ls-files` still lists tracked-but-deleted siblings, and the existence filter must drop them.
8. `git ls-files` failure (non-zero or timeout) must degrade to no siblings, not raise from the step.
9. Regression-shield: a manifest containing only non-.py files (`README.md`, `x.ts`) must not pull in siblings by stem. And a changed test file itself (`tests/test_mod.py`) must not generate siblings.

## Findings
1. MAJOR F1: spec says manifest tests included "as today" but today they are excluded when RED is present. This is a silent behaviour change that conflicts with `test_4961254A...::test_ac8_red_test_paths_takes_priority_over_manifest`. Fix the spec: state the change explicitly, add 4961254A AC8 (and gh804 / 3CE7007C 7A940850-family) to AC6, and update that test's expectation (or define it to still hold) in the RED lot.
2. MAJOR F2: add a RED test for the manifest leg and the dedupe leg: RED + manifest test + sibling in one fix, assert argv contains all, no duplicates, `n_manifest >= 1`, and `n_total` equals the unique count. As written, a GREEN that does not union the manifest passes.
3. MINOR F3: harden `test_args()` against `.py` argv prefix tokens.
4. MINOR F4: define `n_sibling` / `n_total` counting (post-dedupe) and cap order in the spec; consider edges 5 and 6.
5. MINOR F5: edges 2, 3, 4 and 8 are unspecified; at least spec the strip and under-cwd normalisation.
6. MINOR F6: add the `post_fix_pytest_scope` row to `docs/events.md` as an explicit deliverable, with an AC or a grep test.

VERDICT: REJECTED
